# Monitor de Indicadores Epidemiológicos - SUS PE

Aplicação interativa desenvolvida em Python para ingestão, tratamento e visualização de dados abertos de saúde pública em Pernambuco.

## Tecnologias Utilizadas
- Python
- Streamlit
- Pandas
- Plotly

## Fonte dos Dados
Dados públicos extraídos e unificados das bases do DATASUS e Secretarias Estaduais de Saúde (SES-PE).
